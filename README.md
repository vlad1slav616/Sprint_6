Test automation project for the Yandex Samokat service.

Implemented tests
Accordion section "Questions about important things"

Scooter order flow

Order through the upper "Order" button;
Order through the lower "Order" button;
Filling in the order form;
Confirmation of successful order creation.
Logo navigation
Verification that clicking the Samokat logo redirects to the Samokat home page;
Verification that clicking the Yandex logo opens Dzen in a new browser window through redirect.
